# 验证手段档位

<!-- 无浏览器 ≠ 无验证；按下列优先级选择手段。验收标准用它做文字标注。 -->

按优先级从高到低，档位名固定为下列五个（验收标准中的标注必须用这些词）：

- **单测** —— 纯函数 / 几何计算，直接断言是最优解。
- **假 DOM** —— DOM 行为（滚动、焦点、事件、rAF 时序）用假 DOM + 手动驱动 `requestAnimationFrame`，
  以可控假件替代真实渲染（可读写的 `scrollHeight` / `scrollTop`、可手动触发的 `transitionend`、
  可注入的 `matchMedia` 等）。
- **渲染比对** —— 渲染结果、构建产物比对（<!-- 待确认：本项目是否已验证可行 -->）。
- **真机** —— 真实浏览器。可选增强，需人工在桌面应用中打开本会话；**不作为验收门槛**。
- **人工** —— 以上都覆盖不到的，按 `verify.md` 的「人工核对与未实测项」处理。

**单测 / 假 DOM / 渲染比对** 在纯 TUI 会话下即可完成，是**默认路径**。

# 维护规则

<!-- 何时允许修改/删除既有测试。 -->

- 除测试本身有 bug、或新功能使旧测试失去意义外，不得修改或删除既有测试，只能新增。
- 在测试步骤之外修改测试的，单独提交并注明原因。
