# 文档目录说明

项目根下的 `docs` 目录用于存放与项目文档相关的内容。其中的重要文件有：

- `PRELUDE.md`：即本文件，用于说明 `docs` 目录下各文件的信息
- `WORKFLOW.md`：开发流程惯例说明，此文件相对重要，在开始进行开发前都应该了解其内容
- `TARGETS.md`：用于记录推导本项目需求基本准则，确定了当前项目中最重要的用户体验、
  和功能目标。在发现新问题、提出新需求时应该参考本文件。
- `DEV.md`：用于记录面向开发者的项目信息
- `TODO.md`：计划入口，以 Markdown TODO list 的形式记录各个开发目标。
  每个功能组块自带一个一级标题表名身份，各个开发目标则按自身特点下属于不同的功能
  组块。
- `feature/*.md`：特性实施文档
- `review/*.md`：对项目实现的功能报告
- `knowledge/*.md`：为项目问题修正、新需求的提出、功能实现所作的调研，是从项目之
  外获取取的知识。当认为获取到的信息能够帮助未来新功能的开发、旧功能的纠错时，
  就可以把同信息固化为此处的文档。
